# 📊 Data Visualizer CLI

A powerful Python command-line tool for exploring datasets and generating visualizations quickly.

Data Visualizer CLI helps you inspect datasets, discover patterns, generate charts, and produce reports — all directly from the terminal.

---

## 🚀 Features


✔ Load and explore CSV datasets

✔ Preview dataset structure

✔ Generate dataset summary statistics

✔ Detect column types automatically

✔ Identify missing values

✔ Generate visualizations

✔ Interactive Plotly charts

✔ Automatic data visualization

✔ Dataset Explorer

✔ Insight Engine for quick analysis

✔ Dashboard generation

✔ Export analysis as PDF reports

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/MrV3nomous/data-visualizer-cli.git
cd data-visualizer-cli
```

Install dependencies:

```bash
pip install -r requirements.txt
```

---

▶ Usage

Run the program:

```bash
python main.py
```

You will see an interactive menu:

DATA VISUALIZER

1 Load dataset

2 Preview dataset

3 Dataset summary

4 Detect columns

5 Missing values

6 Generate chart

7 Advanced analytics

8 Interactive chart

9 Auto visualization

10 Generate PDF report

11 Dataset Explorer

12 Insight Engine

13 Generate Dashboard

0 Exit


#### Follow the prompts to explore and visualize your dataset.

---

## 📊 Command Line Options

You can also run the program directly with arguments.

#### Load dataset automatically:

```bash
python main.py dataset.csv
```

#### Automatic visualization:

```bash
python main.py dataset.csv --auto
```

#### Generate report:

```bash
python main.py dataset.csv --report
```
